# Web Drones

Landing de **Cota**, servicio de grabación aérea con drones en Valencia.

Es una sola página (`index.html`) sin dependencias. Para verla, abre el archivo en el navegador o activa GitHub Pages (Settings → Pages → rama `main`, carpeta `/`).

Antes de publicarla, cambia el email, el teléfono y los precios de ejemplo.
